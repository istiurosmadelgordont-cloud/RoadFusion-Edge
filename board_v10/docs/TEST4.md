# 测试四：行人及前车危险模拟停车

在原四宫格程序中新增右上“测试四 / AVM”切换、危险监测开关及“确认解除刹车”按钮。测试一红绿灯选车道、行驶方向按钮及测试二五个按钮保留。未新增模型，复用原 YOLO QAT INT8 和 ByteTrack 的真实测量结果。

构建后运行 `sh scripts/run_test4.sh`，或原启动命令追加 `--enable-test4`。普通启动默认关闭测试四，可按 B 或点击危险监测开关。启用测试四不自动启用 UFLD；车道线仍按原方式用 L 开启。

## 行为

- 行人或骑行者的脚点进入行驶区域，且目标具有足够图像尺寸；或连续测量的向内横向运动预测即将进入区域时，累计同一个跟踪目标的危险证据。
- 前方车辆等目标需要位于行驶区域，并满足图像近距占用，或连续框高度增长产生的接近时间条件。不能由相邻车道近车直接触发。
- 同一目标连续两次危险观测才锁定模拟停车。重复时间戳、显示预测框、超过 500 ms 的输入、无效框不累计。
- 可靠且新鲜的本车道几何可用于行驶区域；否则使用屏幕中心的估计区域，并在界面明确标为估计。该区域不能代表已经校准的道路投影。
- 停车锁定会调用现有模拟车辆停止状态，取消测试二变道请求，显示危险目标红框、小型停车提示及全局红色报警。
- 检测断流不会解除已锁定停车。必须至少四次新的非危险观测，覆盖至少一秒，且最新证据不超过 650 ms，才允许点击“确认解除刹车”。解除本身不会起步，需要使用原方向按钮；原红绿灯规则仍保留。
- 关闭测试四不自动起步。切换素材、拖动进度条、视频循环或改变推理输入模式时，重置测试四证据，并停止原模拟车辆。

框高度增长得到的是图像膨胀接近时间。代码保留的米制距离使用现有 NVIDIA 前广角近似参数，仅供信息记录，不作为制动或恢复条件。没有行人灯证据时仅显示“行人进入行驶区域”，不宣称已经判定行人闯红灯。

此功能输出模拟状态与画面，不连接车辆制动执行器，也不把视频播放的停止当作实际车辆已刹停。

## 验证

`test4_safety_regression` 检查行人/车辆危险、路边/相邻车辆排除、真实漏检、跨目标身份、重复帧、过期输入、断流保持停车、危险打断恢复及车道证据新鲜度。

`input_mode_regression` 新增测试四真实控件入口及停车联动验证，保留原测试一、二与车道开关回归。`perception_regression` 覆盖原灯组跟踪及新观测规则。板端素材结果以本次输出目录中的日志、截图和交付记录为准；规则回归不代表检测模型准确率。
