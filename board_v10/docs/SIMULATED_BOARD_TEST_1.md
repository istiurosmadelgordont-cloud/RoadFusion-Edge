# 模拟板端测试一

保存日期：2026-10-15。来源为 RK3568 正在使用的 `/home/cat/rk3568_adas/board_v8`，用于本次视频回放和模拟车辆行为测试。

## 模拟内容与实际执行

方向选择、车辆行驶/停车及红灯强制行驶报警由界面控件模拟。YOLO QAT INT8 与 MobileNet FP16 均通过 RKNN Runtime 在 RK3568 NPU 实际推理。当前回放四路1920×1080拼接输入，每次更新只运行一次960×544 YOLO；MO 输入128×128。车道线、TTC默认关闭。

当前代码包含中文紧凑标签、灯框去重、未确认灯框与标签隐藏、ByteTrack、状态图形叠加开关、方向与灯组ROI绑定，以及新鲜检测结果的连续确认。新七路素材的存在不代表相应场景完成了鸟瞰标定；本版本也未完成自动判断本车车道受哪组信号灯控制。

## 校验记录

- 68个板端源码、脚本、配置和说明文件形成本次导出快照；生成的`build_*`目录未纳入发布。
- 50个C/C++文件的词法标记与导出的板端源码一致；代码未改变。部分既有中文注释在标记完全相同的文件中保留。
- shell脚本使用LF换行，5个启动/构建脚本均通过`sh -n`。
- 在板端独立验证目录完成CMake配置，并构建`adas_four_view`和现有六个回归测试。
- `perception_regression`、`overlay_regression`、`avm_regression`、`preview_resize_regression`、`ufld_decode_regression`、`ui_upload_regression`全部通过。
- 验证构建没有替换正在运行的程序、模型或场景菜单。

## 检测表现的限制

本轮另外对7段夜间素材做了8次方向回放，最终使用无交互的独立板端程序进行统计，避免混入界面切换后的其他视频。仍有明显拒识、箭头方向误分类和漏判，本轮没有新增稳定通过的夜间推荐片段。该结果不是整个模型的数据集精度，已有白天菜单素材也不因此自动变成夜间测试通过。

模型权重、测试视频和编译产物独立保存；仓库提交用于构建和追溯的源码、脚本、场景配置及验证记录。
