# 前车碰撞预警与简洁显示

2026-10-25。基于实际运行的 `board_v10` 修改，保留图像处理工具栏、测试一和测试二控件；自动车道偏离报警仍关闭。测试四的行人/停车规则此次未修改。

## 使用

界面下方、AVM 按钮下面新增“碰撞预警 FCW”按钮，单击切换。它只控制前车碰撞可视化，不改变模拟车辆的行驶状态，不自动启用后向预警。需要有效的本车道检测；车道未就绪时按钮显示等待状态。

```sh
cd /home/cat/rk3568_adas/board_v10
sh scripts/run.pcie.sh --enable-lanes --enable-fcw --no-signal-overlay
```

`--no-fcw` 关闭前车预警。普通启动仍可通过按钮开启。`--no-signal-overlay` 隐藏道路上的大块状态/变道说明，默认启动脚本已加入此参数；右侧原“图形叠加”按钮可重新开启这些说明。检测框、小号距离和车道检测独立保留。

前车旁仅绘制小号 `~xx.x m`，没有浮动大卡片或速度/TTC文字。车道使用单层、18% 近端透明度的柔和颜色覆盖，并向远处渐淡；虚实线样式保留，装饰性的直行箭头取消。车框和距离数字保留风险色以便识别目标。

顶部中间显示黄色“黄色碰撞预警 | 注意车距”和红色“红色碰撞预警 | 前方碰撞危险”；恢复后还原系统标题。既有交通灯/强制实线消息优先于黄色提示，测试四停车消息优先于前车碰撞标题。

## 判断

- 仅使用新检测观测中、脚点位于可信本车道区域的车辆类目标；不使用显示预测框或屏幕中心兜底区域。
- 最近候选切入后重新确认跟踪 ID，速度不继承前一个目标。真实漏检、身份不确定、车道或目标证据超过 650 ms 时清除旧风险和距离。
- 继续使用单目目标高度估距及相对接近速度/TTC估计。默认焦距比例 0.30 用于 NVIDIA 前广角演示，未提供相机实标或绝对车速。
- 演示阈值：距离小于 14 m 或有效 TTC 小于 4 s 为注意候选；距离小于 8 m 或 TTC 小于 2.5 s 为危险候选。连续测量确认及解除迟滞抑制跳色。数值是演示配置和估计结果，不是道路安全距离标准或精确测量。
- 颜色在显示重绘上以 180 ms 时间常数渐变；模型与 NPU 推理次数未增加。

## 验证范围

新增 `fcw_regression` 检查开关、同车道车辆、相邻目标/行人排除、重复帧、切入、真实漏检、过期及三色显示。`input_mode_regression` 检查实际按钮、黄色/红色顶部提示和标题清理，并继续覆盖原测试一/二及 LDW 关闭。原 overlay、跟踪残影、运动补偿、感知、导航和测试四回归亦通过。

实际界面完成开→关→开验证，核对运行二进制和未更换的三份 RKNN 模型哈希。前车预警开启前后，原始 v10 基线样本显示约 7.25 FPS、首次 FCW 样本约 7.08 FPS，素材/目标数不同，不构成严格帧率对照实验；新增 FCW 计算约 0.01 ms。原有 CPU 运动补偿和图像绘制远高于此耗时。

三段 NVIDIA 原片以板端当前 YOLO QAT INT8、UFLDv2 1600×320 INT8 及本模块回放，共 183 个 3 Hz 源帧。`f024c713` 出现绿/黄，`cac16498` 和 `abd705e8` 出现黄/红，三段合计覆盖三档。为匹配 YOLO 前视在四宫格中的输入尺寸，测试其余三格重复前视，不表示四个不同相机视角；媒体时间回放不评价实时端到端延迟。详细结果和原片路径保存在本机 `fcw_material_20261025` 文件夹。
