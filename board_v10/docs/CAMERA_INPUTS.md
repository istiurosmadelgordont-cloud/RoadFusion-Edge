# 相机输入与车道适配

2026-10-26。UFLDv2 没有绑定某个摄像头或某段视频，但当前实现使用固定输入/裁剪及几何有效性检查。分辨率相同或画面更清楚，不保证具有相同的车道推理结果。

## 当前处理

模型输入为 1600×320。当前 `preprocess` 先将图像缩至 1600×533，再取底部 320 行。解码后要求两侧各至少 5 个有效锚点、共同纵向跨度至少占图像高度 16%、空间拟合和左右顺序合理；近端车道宽度须在画面宽度 15%–75% 范围内，另有本车道位置检查。有效几何再参与显示和规则。

## 实际板端对比

使用同一 c581a240 片段的 `front.mp4` 与 `front_tele.mp4`，在 0、3、6、9、12、15、18 秒各取一帧，按四宫格前视 960×540 和 RGB565 转换，调用当前板端 1600×320 INT8 RKNN 及原预处理/几何代码。

| 相机 | 几何通过 | 主要拒绝原因 |
| --- | --- | --- |
| 前广角 | 7/7 | 本批采样均通过 |
| 前长焦 | 1/7 | 2 帧车道过宽；2 帧跨度/拟合未过；2 帧有效车道点不足 |

长焦 0 秒有 72/71 个有效本车道锚点，但近端宽度占画面 82.6%；12 秒有 70/60 个锚点，宽度占 78.8%。这两帧被 75% 上限过滤。6 秒左右均无有效本车道点，18 秒右侧没有有效点；仅放宽宽度门限不能修复这些帧。

同一组 7 个时刻在 PC FP32 上，长焦也只有 1 帧几何有效。这些结果只用于定位问题，不代表完整视频准确率，也不足以量化 FP32 与 INT8 的精度损失。

## 调整方向

1. 保留当前已验证的广角配置，单独建立长焦测试配置；用相机内参或可见道路区域确定几何范围，不全局放宽所有输入。
2. 先离线评估长焦的有效取样高度、近端车道宽度和位置门限，保留足够点数、拟合一致性、左右顺序与证据新鲜度检查。比较原始点与过滤后曲线，分别统计模型漏检和规则拒绝。
3. 对仍缺少车道点的帧，再评估预处理与视角适配；如果改变裁剪/缩放，必须同步校正解码坐标映射，不能只改输入裁剪后沿用旧坐标。训练或模型切换应以多段长焦标注数据验证。
4. 先独立回放，再评估 INT8 输出、完整视频稳定性和板端耗时；验证后才更新默认启动配置。长焦若用于 FCW，还需按实际镜头校准估距参数。

本次上传包含诊断说明，尚未部署长焦专用参数或替换模型。当前已部署的广角链路保持原配置。
