# ARM 暗光增强

复制 host.py 和新增 lowlight.py 到 ARM 原目录，保留其余依赖文件，关闭旧窗口再运行 ./run.sh。无需重新编译驱动。

勾选“暗光增强（预览）”，滑块强度 0～2，默认 1，支持运行时调整。默认关闭。为减少开销，仅处理降采样后的预览；原始 RGB565、保存 PNG/RAW、彩条校验均不受影响。JSON 的 preview_lowlight 记录预览参数，不表示保存图像经过增强。当前 headless 不做增强，识别模型尚未接入。

算法按像素 RGB 最大分量计算共同增益：暗部提升，亮部趋向原值。强度离散为 0.1，查表执行。它是轻量提亮，不包含降噪、去模糊或细节恢复；暗部噪声可能被放大，全黑区域不能恢复信息。颜色比例仅在量化误差范围内保持；不保证信号灯模型准确率提高。

状态栏显示增强耗时，转换总耗时包含增强。SSH X11 显示慢的问题仍然存在。可使用 ./run.sh --preview-step 3 降低预览开销。

五项算法测试通过（零强度、黑白端点、颜色/暗部、灰阶单调性、无效参数），host.py 语法检查通过。ARM 动态视频效果及 GUI 尚需实测。
