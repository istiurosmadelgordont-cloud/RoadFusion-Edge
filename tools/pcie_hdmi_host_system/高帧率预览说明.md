# 高帧率预览

更新文件：host.py、frames.py、preview_queue.py。驱动和 FPGA 协议未改变。

关闭旧窗口，复制以上三个文件到 ARM，运行 ./run.sh。无需为本次 Python 更新卸载驱动或重新上电。

默认预览 960×540，GUI 默认关闭逐像素彩条校验；需要校验可勾选。保存仍为完整 1920×1080。预览使用隔点采样，会牺牲细线等细节；用于检测的模型应使用原始帧。

更低开销：./run.sh --preview-step 3 （640×360）。原尺寸：--preview-step 1。启用 GUI 彩条校验：--check-colorbars。原有 headless 校验默认行为保持不变。

移除了硬件读取循环的固定延时；GUI 每 4ms 检查最新待显示帧，不再每 80ms 显示一帧。旧待显示帧被替换，错误与结束消息单独传递。日志及 FPS 每秒更新。读取 FPS 是 Python 取帧处理循环速率，显示 FPS 是窗口更新速率，都不代表 FPGA 发帧率；接收和显示数量差为应用预览跳帧，不是链路丢帧计数。

本机预览处理对比约 34.6ms -> 4.6ms，不代表 ARM 实测。语法、随机像素转换一致性、最新帧队列、现有五项测试通过。本机 Tcl 库缺失，窗口实测需在 ARM 完成。

底层仍为原有四 DMA 缓冲协议，复制开销及潜在覆盖撕裂限制仍存在。本次不保证无丢帧、无撕裂或某个固定帧率。
