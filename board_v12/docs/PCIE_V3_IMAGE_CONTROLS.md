# board_v12 FPGA图像参数与两阶段回执

本文件名沿用早期pcie_v3接入记录，正文适用于当前board_v12与PCIe驱动8.2。主程序实时采集已使用DMA-BUF/RGA，不再按board_v10/read路径部署。运行方式见 [板端README](../README.md)。

## 参数与界面

界面提供10套预设、11个开关和13个数值参数，覆盖DCP去雾、亮度双边降噪、Gamma、CLAHE、暗部调整与高光保护等。降噪sigma限16/32/48；Gamma采用固定LUT，运行时不任意更换曲线。暂停中的HSV/金字塔多尺度融合实验没有加入当前位流。

控件编辑只修改共享草稿。选择预设后，点击应用才提交整包五字参数；详细窗口可编辑同一草稿，不暂停视频。恢复默认仅编辑草稿，恢复旁路并应用才实际提交。新开程序的草稿不代表FPGA真实参数读回，STOP不自动清除硬件图像配置。

参数作用于整张合成图，不是某个相机ROI；RGA缩放不改变FPGA配置。文件回放允许浏览但禁止向硬件提交。独立控制线程与视频处理分开，界面不阻塞等待ioctl。

## 寄存器与回执

| BAR1偏移 | 语义 |
| --- | --- |
| 0x200/0x204/0x208/0x20C/0x210 | 五个32位参数字，形成160位快照 |
| 0x214 | 提交唯一非零cookie |
| 0x218 | 可选128字节独立DMA确认区地址 |

FPGA跨时钟域握手接收完整配置，在图像入口帧边界统一应用。确认区+0为RECEIVED，+64为APPLIED，两者携带相同cookie与参数；主机需核对事务匹配。

SUBMIT成功、寄存器写成功、视频TX完成或STOP确认不能替代APPLIED。APPLIED只表示入口生效，后续图像到显示器还需经过流水线和传输。

超时保留在途事务并继续接收迟到回执，不自动重发或覆盖。持续超时需正常停止、排空，再检查位流和驱动匹配。驱动支持参数能力不证明FPGA固件版本正确；7.0旧工具只有单向提交，不能确认硬件生效。
