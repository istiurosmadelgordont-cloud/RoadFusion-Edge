# 模拟导航面板

适用当前board_v12。方向和距离由人工输入，不包含视频导航OCR、地图定位或真实里程测量，界面标注模拟导航。

当前 `run_pcie.sh` 已默认传入 `--demo-navigation`。`sh scripts/run_navigation_demo.sh` 会使用同一PCIe/NPU链路并显式关闭测试四；需要联合危险监测时可运行 `sh scripts/run_pcie.sh --enable-test4`。裸二进制未传该参数时的默认值与脚本不同。

按钮选择左转/直行/右转，模拟距离每次增减30米、下限0，支持重置120米。距离不会随时间伪装成真实路程。

距离大于20米时按当前直行方向匹配灯态，进入模拟路口范围后按所选方向匹配对应灯态；红灯停车，未确认灯态等待，对应绿灯连续确认后给出模拟建议。已启用测试四且存在危险停车锁定时，停车建议优先。

导航建议不替代测试一按钮表示的人工行驶状态，不控制真实车辆。导航、测试四、AVM切页与各自开关分开；车道检测仍需单独开启。

`navigation_demo_regression`覆盖方向、距离边界、准备/转向、停止优先、方向灯连续确认及过期灯态；`input_mode_regression`覆盖交互入口。规则回归不证明导航视频识别已实现。
