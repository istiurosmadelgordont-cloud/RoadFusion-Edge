## 保留的 RGA 路径

FPGA RGB565 → driver 8.2 DMA-BUF → 同步 RGA → 页对齐完整 BGR 池。
预览、YOLO/MO/UFLDv2 前处理和 PCIe 软件显示缩放保留最新 RGA 实现；固定 RGA 输入，移除 read/CPU 预览切换。保留颜色修复、有界缓冲池、ROI 寿命和 STOP 处理。
当前 UI 的四宫格预览为 656×369，单路为 1328×747，主视角优先为 960×540 加三路 432×243；保持 16:9 完整画面，RGA 缓冲池按实际布局懒加载并有界复用。

## 构建和启动

```sh
cd /home/cat/board_v12
sh scripts/build.sh
sh scripts/run_pcie.sh
sh scripts/run_pcie.sh --enable-lanes --enable-fcw
# 本地鸟瞰素材演示
sh scripts/run_avm_473423e3.sh
```

`run_pcie.sh` 现在自动准备驱动：复用已加载的 8.2；未加载时检查本目录模块，必要时按当前内核编译并加载，随后检查 PCIe/RGA 权限及 NPU 驱动。需要提权时使用 sudo。原板端 pcie_v3 的 Xfce 登录恢复记录已移除，详见 [启动调整](docs/STARTUP_20261029.md)。
