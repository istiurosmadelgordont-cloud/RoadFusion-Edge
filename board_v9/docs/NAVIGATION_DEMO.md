# 测试三：PCIe 视频上的模拟导航面板

用户确认当前 PCIe 视频没有导航画面，并授权先模拟。此版本不包含 OCR、地图定位或真实导航距离：方向与距离由面板按钮提供，画面持续标注“模拟导航”和“尚未接入导航识别”。

运行 `sh scripts/run_navigation_demo.sh`，或原 PCIe 启动命令追加 `--demo-navigation --no-test4`。四路视频、YOLO 与灯态继续来自原 PCIe/NPU 链路。普通程序未指定该参数时，保持原测试四 / AVM 界面。

右上角默认显示模拟“前方 120 米右转”。按钮可以选择左转、直行、右转，距离每次增减 30 米，最低为零，支持重置为 120 米；距离不会随时间自动伪装成真实路程。

模拟距离大于 20 米时，建议仍按当前直行方向匹配真实灯态；进入模拟路口范围后，按所选导航方向匹配对应灯态。确认红灯显示“红灯停车”，灯态未确认时显示等待，确认对应绿灯才显示保持直行或模拟转向。若启用了测试四且存在停车锁定，危险停车建议优先。

“模拟建议”是导航演示模块的输出，不替代测试一按钮代表的人工模拟行驶状态，也不自动操纵真实车辆。测试一红绿灯、测试二变道与测试四按钮保留；右上角按钮依次切换导航、测试四、AVM。车道线仍可以用原 L 键开关。

`navigation_demo_regression` 检查方向、距离上下界、手动按钮、准备/转向状态、停止优先级、正确方向灯的连续确认及过期灯态；`input_mode_regression` 继续检查原有控件与测试四联动。
