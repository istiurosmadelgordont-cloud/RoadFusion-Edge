## 共用 LUT 的含义

以下三组前左 / 前中 / 前右视频共同估计一套相机映射参数，**三组共用同一套 12 个 BRAM 初始化 hex**，运行时无需按视频组切表：

- `02_sunny_dashed_solid_473423e3`
- `03_sunny_middle_lane_fdab85ad`
- `04_daylight_cloudy_backup_47e8da5f`

“共用”指三组素材共用一套映射；每个相机仍有独立映射（left/center/right 各 4 bank），并非三路相机读取完全相同的坐标。

实际加载位置 `fusion_maps/grid16_bram`。16 像素网格，每相机 121×35 节点；每 bank 1098 个 36 位 Q10.8 节点，u 在低 18 位、v 在高 18 位，全 1 无效。详见包内 `sim/panorama/SHARED_LUT_20261027.md`、`config.json` 和 `geometry.json`。

保留固定接缝 **x=640 / 1280、128 像素羽化**。动态接缝实验已经回退；未启用窄带羽化。LUT 是综合期 BRAM 初值，没有运行时写入接口；换表需重建并下载新 bit。

## 输入、输出与按键

| DDR 通道 | 实际输入 | 融合视角 | 四宫格位置 |
| --- | --- | --- | --- |
| 0 | HDMI | 前左 | 左上 |
| 1 | 以太网1 | 前中广角 | 右上 |
| 2 | 以太网0 | 前右 | 左下 |
| 3 | SFP（板卡二回传） | 不参与融合 | 右下 |

每路 960×540 RGB565。融合为 1920×540，位于 1920×1080 上半区，下半区黑色；四宫格为完整 1920×1080。HDMI 与 SFP 共用同一输出。

**KEY2：L15 / 3.3 V / LVCMOS33 / 低电平按下**。上电默认融合，每按一次切换融合 / 四宫格；消抖沿用原 `Key_anti_shake.v`，KEY1 保留复位。等待完整结果生成后，在垂直消隐期切换。

包含 **缺 SFP 的模式切换修复**：四宫格只锁定已有完整帧的输入，未就绪象限输出黑色；SFP 初始未接入时，其他三格仍可更新，不再一直等待第四路。三路融合仍要求通道 0、1、2 都有完整帧。

`source_valid` 表示曾收到完整帧的粘滞状态，**不是实时在线检测**。已经有帧后再拔线，可能保留末帧；不保证自动变黑。各路页面锁定不等于相机曝光或视频时间戳同步。

以太网0：`192.168.1.10 / A0-B1-C2-D3-E4-E4`；以太网1：`192.168.1.11 / A0-B1-C2-D3-E1-E1`，UDP 1234。系统接线及发送说明见 [双板说明](../README.md)。
